# Gapless Chromosome-Scale Genome Assemblies and Annotations of AB and TU Zebrafish
This repository provides high-contiguity, gapless chromosome-scale genome assemblies and associated gene annotation files for two zebrafish stocks, AB and TU, maintained at the China Zebrafish Resource Center (CZRC).

1. Genome assemblies
  Two independent zebrafish genome assemblies are provided:
  CZRC-AB1.0 (AB; 1.49 Gb)
  CZRC-TU1.0 (TU; 1.58 Gb)

  Both assemblies were generated using Oxford Nanopore Technologies (ONT) ultra-long reads and MGI short-read sequencing data from individual adult male zebrafish. 
  Previously published Hi-C datasets were used for chromosome-scale scaffolding.
  Each assembly contains 25 gapless chromosome-scale sequences without ambiguous N bases. These resources are described as gapless chromosome-scale assemblies.

2. Available files
  The following files are provided for each genome assembly:
  Genome sequences: FASTA files.
  Gene annotations: GFF files.
  File integrity: MD5 checksums for verifying downloaded files.

3. Data availability
  Genome assembly sequences, gene annotation files, and MD5 checksums will be available through the Releases section of this repository.
  Raw sequencing data are available through NCBI BioProject PRJNA1368386.
